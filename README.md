# MKserial.local

A real-time encrypted chat website where PRIVACY MATTERS!
It's designed for people who needs real privacy online, where you can chat anonymously without worrying about your digital identity and being tracked. (Inspired by WikiLeaks).

## Features
- User registration & login
- Create and join chat rooms
- Direct messages
- Real-time messaging via WebSockets

## Tech Stack
- Node.js + Express
- Socket.io
- SQLite
- Vanilla HTML/CSS/JS frontend
